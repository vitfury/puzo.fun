# 📘 Як використати цю документацію з Claude Code

## Крок 1: Підготуй репозиторій

### 1.1 Створи порожній репозиторій на GitHub
```bash
# На GitHub: створи новий репозиторій "melody-ninja"
# Не додавай README, .gitignore, license - все буде створено локально
```

### 1.2 Клонуй його локально
```bash
git clone https://github.com/твій-username/melody-ninja.git
cd melody-ninja
```

### 1.3 Скопіюй всі файли документації

Помісти в корінь репозиторію такі файли (які я створив вище як artifacts):

```
melody-ninja/
├── README.md                           # Головний readme
├── .gitignore                          # Git ignore
├── .env.example                        # Приклад env змінних
├── .project-structure                  # Структура проекту
├── docker-compose.yml                  # Docker конфігурація
├── CLAUDE_CODE_INSTRUCTIONS.md         # Інструкції для Claude Code
├── IMPLEMENTATION_CHECKLIST.md         # Чеклист реалізації
├── QUICK_START.md                      # Швидкий старт
├── HOW_TO_USE_WITH_CLAUDE_CODE.md     # Цей файл
└── docs/
    └── TECHNICAL_SPEC.md               # Повне ТЗ (з файлу music_gamification_tz.md)
```

### 1.4 Створи структуру папок
```bash
mkdir -p backend frontend docker docs
mkdir -p docker/ssl
```

### 1.5 Створи Docker файли
Помісти файли які я створив:
- `docker/Dockerfile.backend`
- `docker/Dockerfile.frontend`
- `docker/nginx.conf`

### 1.6 Зроби перший commit
```bash
git add .
git commit -m "Initial commit: Project documentation and structure"
git push origin main
```

## Крок 4: Комунікація з Claude Code

### Варіант А: Дай загальне завдання (рекомендується)

Просто скажи:

```
Привіт! Мені потрібно створити повний веб-додаток Melody Ninja.

Вся документація є в репозиторії:
- CLAUDE_CODE_INSTRUCTIONS.md - головні інструкції
- IMPLEMENTATION_CHECKLIST.md - детальний чеклист
- docs/TECHNICAL_SPEC.md - повна технічна специфікація
- QUICK_START.md - швидкі команди

Почни з Фази 1 (Базова інфраструктура) згідно з CLAUDE_CODE_INSTRUCTIONS.md.

Створи:
1. Базову структуру Laravel проекту в папці backend/
2. Базову структуру React проекту в папці frontend/
3. Всі необхідні Docker файли
4. Перевір що docker-compose up -d працює

Потім почнемо з міграцій бази даних.
```

### Варіант Б: Поетапна розробка

Якщо хочеш більше контролю, давай завдання поетапно:

**Етап 1: Інфраструктура**
```
Створи базову інфраструктуру проекту:
1. Ініціалізуй Laravel в папці backend/
2. Встанови всі необхідні пакети (дивись QUICK_START.md)
3. Налаштуй .env файл
4. Створи базову структуру папок згідно .project-structure
```

**Етап 2: База даних**
```
Створи всі міграції для бази даних:

```

**Етап 3: API Endpoints**
```
Створи всі API endpoints згідно IMPLEMENTATION_CHECKLIST.md:

- ... і так далі
```

І так по кожному етапу з IMPLEMENTATION_CHECKLIST.md

## Крок 6: Корисні команди під час розробки

### Перевірка стану проекту
```bash
# Подивитись git статус
git status

# Подивитись що змінилось
git diff

# Подивитись логи Docker
docker-compose logs -f app
```

### Тестування
```bash
# Перевірити Laravel
docker-compose exec app php artisan --version

# Запустити міграції
docker-compose exec app php artisan migrate

# Запустити seeders
docker-compose exec app php artisan db:seed

# Запустити тести
docker-compose exec app php artisan test
```

### Frontend
```bash
# Перевірити React
cd frontend && npm run build

# Запустити dev сервер окремо
npm start
```
