# 🚀 Швидкий старт

## Перший запуск

Просто виконай одну команду:

```bash
make install
```

Ця команда:
1. ✅ Перевірить чи встановлений Docker
2. ✅ Скопіює всі конфігураційні файли
3. ✅ Запустить MySQL та Redis
4. ✅ Дочекається готовності бази даних
5. ✅ Встановить PHP залежності (Composer)
6. ✅ Згенерує ключ Laravel
7. ✅ Створить таблиці в базі
8. ✅ Встановить Node залежності (npm)
9. ✅ Запустить всі сервіси Docker

## Після першого запуску

Наступного разу просто:

```bash
make up
```

Або:

```bash
docker compose up -d
```

## Перевірка

Відкрий у браузері:
- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost/api/health

## Корисні команди

```bash
make logs      # Дивитись логи
make down      # Зупинити все
make restart   # Перезапустити
make help      # Показати всі команди
```

## Troubleshooting

Якщо щось не працює:

```bash
make clean     # Видалити все
make install   # Встановити заново
```
