# Адмін панель: Управління активностями

## Огляд

Система управління активностями дозволяє адміністраторам створювати, редагувати та планувати щоденні активності для користувачів. Активності можна налаштувати так, щоб вони з'являлися та зникали у певні дати.

## Доступ

1. Увійдіть як адміністратор:
   - Email: `admin@melody.ninja`
   - Password: `admin123`

2. Перейдіть до адмін панелі: `/admin`
3. Виберіть "Activities Management" (Управління активностями)

## Функції

### Створення активності

1. Натисніть кнопку **"Create New Activity"**
2. Заповніть форму:
   - **Activity Name** - назва активності (напр. "Morning Stretch")
   - **Type** - тип активності:
     - `Daily Tasks` - щоденні завдання
     - `Ongoing Rules` - постійні правила
     - `Music Walks` - музичні прогулянки
   - **Points** - кількість балів за виконання
   - **Order** - порядок відображення (чим менше число, тим вище)
   - **Description** - опис активності (опціонально)
   - **Active From** 📅 - дата початку активності
   - **Active To** 📅 - дата закінчення активності
   - **Is Active** - чи активна активність зараз

3. Натисніть **"Create"**

### Планування з календарем

**Календар дозволяє налаштувати, коли активність буде доступна користувачам:**

- **Active From** - активність з'явиться у користувачів тільки з цієї дати
- **Active To** - активність зникне після цієї дати
- Якщо обидві дати не вказані - активність постійна
- Якщо вказана тільки `Active From` - активність з'явиться з цієї дати назавжди
- Якщо вказана тільки `Active To` - активність зникне після цієї дати

**Приклади:**

```
1. Новорічна активність:
   Active From: 2025-12-25
   Active To: 2026-01-07
   → Активність буде доступна тільки на зимові свята

2. Літня активність:
   Active From: 2025-06-01
   Active To: 2025-08-31
   → Активність доступна тільки влітку

3. Нова постійна активність:
   Active From: 2025-10-20
   Active To: (не вказано)
   → Активність з'явиться 20 жовтня і залишиться назавжди
```

### Редагування активності

1. Натисніть кнопку **"Edit"** біля потрібної активності
2. Змініть необхідні поля
3. Натисніть **"Update"**
4. Або натисніть **"Cancel"** для відміни

### Видалення активності

1. Натисніть кнопку **"Delete"** біля активності
2. Підтвердіть видалення у діалозі

### Тимчасове вимкнення

Замість видалення активності, ви можете:
1. Зняти галочку **"Is Active"**
2. Або встановити `Active To` у минуле

Це дозволить зберегти історію виконання користувачів.

## Типи активностей

### Daily Tasks (Щоденні завдання)
Завдання, які користувачі можуть виконати один раз на день.
- Приклади: "Morning Stretch", "Log Breakfast", "Evening Reflection"
- Скидаються щодня о 6:00 AM

### Ongoing Rules (Постійні правила)
Правила, які користувачі повинні дотримуватись щодня.
- Приклади: "Stay Under Calorie Limit", "Hit 10,000 Steps"
- Скидаються щодня о 6:00 AM

### Music Walks (Музичні прогулянки)
Спеціальні активності, пов'язані з прослуховуванням музики під час прогулянок.
- Приклади: "Music Walk"
- Інтеграція з жанрами музики

## Технічні деталі

### Backend

**API Endpoints:**
- `GET /api/v1/admin/activities` - список всіх активностей
- `POST /api/v1/admin/activities` - створити активність
- `GET /api/v1/admin/activities/{id}` - отримати активність
- `PUT /api/v1/admin/activities/{id}` - оновити активність
- `DELETE /api/v1/admin/activities/{id}` - видалити активність

**Валідація:**
- `active_to` повинна бути >= `active_from`
- Всі дати зберігаються у форматі `YYYY-MM-DD`

**Фільтрація для користувачів:**
Endpoint `/api/v1/activities/today` автоматично фільтрує активності по даті:
```php
Activity::activeOnDate(Carbon::today())
```

### Frontend

**Файли:**
- `/frontend/src/pages/admin/AdminActivitiesPage.tsx` - сторінка управління
- `/frontend/src/api/admin.ts` - API клієнт
- `/frontend/src/i18n/locales/{en,uk}.json` - переклади

**Компоненти:**
- Нативні HTML5 date inputs для вибору дат (темна тема)
- Форма створення/редагування
- Список активностей з inline editing

## Поради

1. **Порядок відображення**: Використовуйте `Order Index` щоб контролювати порядок активностей (0, 10, 20, 30...)
2. **Тимчасові активності**: Для святкових або сезонних активностей використовуйте календар
3. **Тестування**: Створіть тестову активність з `Active From = сьогодні` щоб перевірити роботу
4. **Бекап**: Перед видаленням активності переконайтесь, що збережена історія користувачів

## Приклад використання

**Сценарій:** Додати новорічну активність "Снігова прогулянка"

1. Відкрийте `/admin/activities`
2. Натисніть "Create New Activity"
3. Заповніть:
   - Name: "Снігова прогулянка"
   - Type: Music Walks
   - Points: 50
   - Description: "Прогуляйтесь і насолодіться зимовою атмосферою"
   - Active From: 2025-12-20
   - Active To: 2026-01-10
   - Is Active: ✓
   - Order: 100
4. Натисніть "Create"

Тепер користувачі побачать цю активність тільки в період з 20 грудня по 10 січня!
