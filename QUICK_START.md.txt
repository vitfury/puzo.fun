# 🚀 Quick Start Guide

## Для Claude Code

Привіт, Claude Code! Ось що тобі потрібно зробити:

### 1. Створити базову структуру проекту

```bash
# Створити основні папки
mkdir -p backend frontend docker docs

# Backend папки
mkdir -p backend/app/{Models,Http/Controllers,Http/Middleware,Services,Jobs,Notifications}
mkdir -p backend/database/{migrations,seeders}
mkdir -p backend/routes
mkdir -p backend/config
mkdir -p backend/storage/{app,framework,logs}

# Frontend папки
mkdir -p frontend/src/{components,pages,services,hooks,utils,styles,assets}
mkdir -p frontend/public

# Docker папки
mkdir -p docker/ssl

# Docs папки
mkdir -p docs
```

### 2. Ініціалізувати Laravel

```bash
cd backend
composer create-project laravel/laravel .
composer require laravel/sanctum
composer require kreait/firebase-php
composer require guzzlehttp/guzzle
composer require laravel/horizon
composer require spatie/laravel-permission
cd ..
```

### 3. Ініціалізувати React

```bash
cd frontend
npx create-react-app .
npm install react-router-dom axios reactflow firebase
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
cd ..
```

### 4. Створити Docker файли

Файли вже підготовлені в artifacts:
- `docker-compose.yml` - в корені
- Потрібно створити ще `docker/Dockerfile.backend` та `docker/Dockerfile.frontend`

### 5. Налаштувати .env

Скопіюй `.env.example` в `.env` та заповни необхідні змінні:

```bash
cd backend
cp .env.example .env
php artisan key:generate
cd ..
```

### 6. Створити міграції

Це найважливіша частина! Створи міграції для всіх таблиць згідно з `IMPLEMENTATION_CHECKLIST.md`

Приклад команди:
```bash
cd backend
php artisan make:migration create_genre_nodes_table
php artisan make:migration create_user_genre_progress_table
# ... і так для всіх таблиць
cd ..
```

### 7. Запустити Docker

```bash
docker-compose up -d
```

### 8. Запустити міграції

```bash
docker-compose exec app php artisan migrate --seed
```

## Швидкі команди для роботи

### Backend
```bash
# Створити model
docker-compose exec app php artisan make:model GenreNode -m

# Створити controller
docker-compose exec app php artisan make:controller Api/GenreController

# Створити service
mkdir -p backend/app/Services
# Створити файл вручну

# Створити job
docker-compose exec app php artisan make:job SyncStravaData

# Створити notification
docker-compose exec app php artisan make:notification DailyReminderNotification

# Запустити тести
docker-compose exec app php artisan test

# Запустити queue
docker-compose exec app php artisan queue:work

# Очистити кеш
docker-compose exec app php artisan cache:clear
docker-compose exec app php artisan config:clear
```

### Frontend
```bash
# Запустити dev server
cd frontend
npm start

# Створити build
npm run build

# Встановити пакет
npm install package-name
```

### Docker
```bash
# Запустити контейнери
docker-compose up -d

# Зупинити контейнери
docker-compose down

# Перебудувати контейнери
docker-compose up -d --build

# Подивитися логи
docker-compose logs -f app

# Зайти в контейнер
docker-compose exec app bash
```

## Важливі нотатки для Claude Code

### Пріоритети
1. **Функціональність > Красота** - спочатку зроби щоб працювало, потім зроби красиво
2. **MVP спочатку** - базові функції важливіші за додаткові
3. **Тести важливі** - пиши тести для критичної логіки
4. **Документація** - коментуй складний код

### Де шукати інформацію
- Повна специфікація: `docs/TECHNICAL_SPEC.md`
- API endpoints: `IMPLEMENTATION_CHECKLIST.md`
- Архітектура: `README.md`

### Коли щось незрозуміло
1. Перечитай `docs/TECHNICAL_SPEC.md`
2. Подивись на приклади в IMPLEMENTATION_CHECKLIST
3. Питай уточнення якщо потрібно

### Best Practices
- Використовуй Eloquent relationships замість raw SQL
- Валідуй всі inputs через Form Requests
- Використовуй Services для бізнес-логіки
- Jobs для асинхронних операцій
- Events & Listeners для слабкозв'язаної архітектури
